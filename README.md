# 🌍 World Development Clusters Using Machine Learning

## 📌 Project Overview

World Development Clusters is a Machine Learning project that analyzes and groups countries based on their socio-economic and development indicators.

The project applies unsupervised machine learning algorithms to identify countries with similar development characteristics. It helps explore global development patterns and understand similarities and differences between countries.

An interactive web application built using **Streamlit** allows users to explore country clusters and visualize the results.

## 🎯 Objectives

- Analyze global country development indicators.
- Group countries based on similar development characteristics.
- Apply unsupervised machine learning algorithms.
- Visualize country clusters using dimensionality reduction.
- Build an interactive dashboard for exploring results.
